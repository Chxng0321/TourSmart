
# 🌎 TourSmart

### Plataforma turística inteligente del norte del Perú

TourSmart es una plataforma web desarrollada para facilitar la exploración de destinos turísticos, especialmente las playas de Piura y Tumbes.

Su objetivo es brindar información sobre destinos, actividades y ubicaciones para ayudar a los usuarios a planificar sus viajes.

## 🏖️ Destinos disponibles

- Máncora
- Vichayito
- Zorritos
- Punta Sal
- Los Órganos
- Cabo Blanco
- Colán
- Yacila

## 🚀 Funcionalidades

- Registro e inicio de sesión de usuarios.
- Exploración de destinos turísticos.
- Información detallada de cada playa.
- Mapas de ubicación integrados.
- Sistema de playas favoritas.
- Buscador de destinos.
- Filtros por región, presupuesto y tipo de playa.
- Diseño adaptable a diferentes dispositivos.

## 💻 Tecnologías utilizadas
